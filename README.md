# 🏦 Java Banking System

A simple and clean Banking System built using Core Java concepts. This project demonstrates my understanding of Object-Oriented Programming.

### 🚀 Features
- Create Bank Account with Account Number & Initial Balance
- Deposit Money with validation
- Withdraw Money with insufficient balance check
- Check Current Balance

### 💻 Tech Stack
- Java
- OOPs Concepts (Encapsulation, Constructor)

### 📂 How to Run
1. Clone the repo: `git clone https://github.com/arun-btech509/java-banking-system`
2. Compile: `javac BankAccount.java`
3. Run: java ATM
